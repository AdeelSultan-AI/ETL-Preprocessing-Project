# ETL Preprocessing Project - Retail Store Sales

## 📌 Project Overview
This project implements a complete ETL pipeline for Retail Store Sales data. The main goal is to clean raw sales data and make it ready for analysis.

## 🛠️ Tools Used
- Python
- Pandas, NumPy
- Matplotlib

## 📂 Files
- `retail_store_sales.csv` -> Raw data
- `ETL prastice.py` -> ETL Python code
- `cleaned_retail_store_saless.csv` -> Cleaned data

## 🔄 ETL Process
1.  **Extract:** Loaded raw data
2.  **Transform:** Handled missing values, removed duplicates, fixed data types, removed outliers
3.  **Load:** Saved clean data
